# Research Methods and Evidence Ledger

## What this pack does
This is a selected-reference library, design synthesis, and implementation backlog. It is not an exhaustive account of every Roblox game, a live competitor playthrough, a finished Roblox project, or a revenue forecast. The term “AI slop” is treated as a fast, absurd, colorful aesthetic; production reliability still matters.

## Inspection labels
| Label | Meaning |
|---|---|
| page-read | Relevant visible page content was inspected |
| search-excerpt | The research tool supplied supporting passages; a full page review is not claimed |
| page-opened | The reference page was opened/identified; content depth is limited |
| transcript-reviewed | Timestamped on-page video text/description inspected; full playback is not claimed |
| legacy-unverified | Inherited link retained without promoting its prior summary to verified evidence |
| design-proposal | Original suggested implementation, test, price, timing, or mechanic |
| not-started | Build card with no game implementation evidence yet |

All research dates use the user's date, **2026-10-17**. Sources can change; recheck APIs, product requirements, eligibility, limits, and prices when implementing. Prefer current Roblox, tool-maintainer, Obsidian, and OpenAI documentation over tutorial snippets for technical claims.

## Corrections to the first pass

Earlier verification used invented expected lengths and described a shell rollback that had failed; those claims are superseded by the new recorded audit and separately tested transactional rollback. The earlier artifacts are preserved rather than silently rewritten as history.

## Observation versus inference
The attached gameplay screenshot supports colors, visible UI placement, silhouettes, and composition. It does not show hidden server rules, product fulfilment, economy rates, or player retention. The graph screenshot is a desired **shape and density**, not evidence about the contents of that vault. The new graph comes from real note links, not placeholder dots.

## Search boundaries
All selected sources and retained earlier references have notes in the Reference Library. Unrelated search results, advertisements, recommendation widgets, sponsored signup links, and contact details are not imported as game-development references. Failed guessed URLs are not listed as functioning authority; the quest-design link was resolved to the current introduction page. No remote media files or full copyrighted transcripts were downloaded.

## Further research tasks
Review a controlled real-game session; record screenshots/observations with permission; verify any exact API before coding; run the smallest prototype; append evidence to the relevant decision. Research should shrink implementation uncertainty, not merely increase node count.
