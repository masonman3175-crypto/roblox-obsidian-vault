# Ultimate Slop Hub

One Obsidian vault for all of Cade + partner's quick Roblox "homepage" games (simulators, obbies, tycoons). Shared blueprint, shared wiki, one folder per game.

- Start here: `00 Hub.md`
- The recipe every game follows: `blueprint/Slop Blueprint.md`
- AI rules: `CLAUDE.md` (Claude Code) and `AGENTS.md` (Codex)

Open the repo folder as an Obsidian vault. Manual sync: run `.sync-vault.ps1` (pull, commit, push). The AIs pull before and push after every change on their own.
