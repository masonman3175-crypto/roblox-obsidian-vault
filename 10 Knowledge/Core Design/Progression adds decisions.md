# Progression adds decisions

> [!note] Evidence boundary
> This is an original implementation/design proposal. Sources below supply background or API guidance; proposed timings, quantities, and business results are not established facts.

## Decision
Unlock new interactions and routes rather than only multiplying income indefinitely.

## Implementation and rationale
Start with one-slot carrying, then unlock route gadgets or alternate delivery goals. Keep movement advantages bounded so the map remains navigable. A new zone should introduce a new guardian rule or route problem, not merely a different floor color and larger required number. Track time to first meaningful choice.

## Acceptance test
- [ ] Compare a new account and a veteran on the same arena. Both should have useful decisions and understand why an upgrade helps.
