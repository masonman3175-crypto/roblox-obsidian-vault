# MOC - Colorful UI

**Guiding question:** Can a new touch/controller player understand the next action and evaluate purchases?

Read the decision notes below, then use a linked build card or robot prompt to implement one slice. These notes are proposed project decisions rather than copied game rules.

## Decision notes
- [[A reusable toy-box visual system]]
- [[HUD hierarchy and safe play space]]
- [[Chunky buttons with honest states]]
- [[Shop browsing before checkout]]
- [[Purchase flow is a state machine]]
- [[Index cards that guide exploration]]
- [[Rarity communicates through more than color]]
- [[Mobile thumb zones and safe areas]]
- [[Controller focus is a first-class state]]
- [[Bright style without unreadable information]]
- [[Juice with an off switch]]
- [[One modal at a time]]
- [[Contextual guidance that ends]]
- [[Useful loading and error states]]
- [[Destructive actions need a preview]]
