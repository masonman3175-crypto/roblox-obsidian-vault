# MOC - Monetization

**Guiding question:** What optional value is offered and how is every legitimate grant fulfilled?

Read the decision notes below, then use a linked build card or robot prompt to implement one slice. These notes are proposed project decisions rather than copied game rules.

## Decision notes
- [[Many products through one catalog]]
- [[Cosmetics can carry catalog breadth]]
- [[Starter bundle after demonstrated value]]
- [[Temporary boosts have an explicit clock]]
- [[Products are not all the same entitlement]]
- [[Paid randomness decision gate]]
- [[Per-player product availability]]
- [[Odds table as one source of truth]]
- [[Runtime prices not painted prices]]
- [[Offer placement without modal spam]]
- [[Free and premium season tracks]]
- [[Recurring value needs recurring production]]
- [[Private servers as an optional social product]]
