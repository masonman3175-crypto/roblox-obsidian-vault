# Open-source libraries, plugins and asset sources

Links checked on 2026-10-20 (HTTP 200). Descriptions are short summaries from search results and general knowledge; check each project's README for current status and licence before depending on it.

## Roblox UI libraries and state
- [Fusion](https://github.com/Elttob/Fusion): reactive UI library for Luau with `Spring` (physics animation) and `Tween` helpers.
- [react-luau](https://github.com/Roblox/react-luau): Roblox's port of React (17.x), with Bindings for efficient animation.
- [Roact](https://github.com/Roblox/roact): the older Roblox UI library that react-luau succeeds; check status before starting new work with it.
- [Rodux](https://github.com/Roblox/rodux): Redux-style state container for Roblox.
- [Iris](https://github.com/SirMallard/Iris): immediate-mode GUI (Dear ImGui style) for debug and tool UIs.
- [Quark](https://github.com/creepersaur/quark): small reactive UI library (MIT per its listing).

## Camera, effects and utilities
- [RbxCameraShaker](https://github.com/Sleitnick/RbxCameraShaker): camera-shake module ported from the Unity "EZ Camera Shake" asset (see also the [DevForum thread](https://devforum.roblox.com/t/ez-camera-shake-ported-to-roblox/98482)).
- [RbxUtil](https://github.com/Sleitnick/RbxUtil): collection of Luau utility modules by Stephen Leitnick.
- [NevermoreEngine](https://github.com/Quenty/NevermoreEngine): large module collection used for UI, animation and gameplay helpers.
- [Jad's Emit Plugin](https://devforum.roblox.com/t/dear-vfx-makers-i-present-to-you-jads-emit-plugin/1986838): DevForum plugin for previewing/emitting VFX.
- [VFX system update features](https://devforum.roblox.com/t/vfx-system-update-features/1293316): DevForum thread on Roblox VFX capabilities.
- [useful-roblox-resources](https://github.com/Loominagit/useful-roblox-resources): community-curated list of Roblox modules and tools.

## Reference and asset sources
- [Game UI Database](https://www.gameuidatabase.com/about.php): 55k+ game UI screenshots, filterable by texture, pattern and colour.
- [itch.io game assets](https://itch.io/game-assets): GUI, VFX, animation and sound packs (check each licence); galleries in [`previews/`](previews/README.md).
- [OpenGameArt](https://opengameart.org/content/interface-sounds), [Kenney](https://kenney.nl/assets/category:Audio), [Freesound](https://freesound.org): sound sources.
- BuiltByBit Roblox UI kits (cited in `ui-styles/GUI-STYLES.md`): marketplace listings; the site blocks automated downloads, so no images from it are bundled.
