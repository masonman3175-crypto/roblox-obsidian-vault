# 25 additional animation references

These are **original concept references**, not downloaded artwork, licensed files, or tested Roblox implementations. Each entry provides a distinct design brief for AI-assisted development. Validate accessibility, performance, and implementation in Studio before shipping.

Creator Hub background: https://create.roblox.com/docs/ui/animation

1. **Score increment roll** — Animate the visible number from prior value to the new score.
2. **Badge unlock flourish** — Scale in the badge and settle to a still state.
3. **Quest complete sweep** — Sweep a short highlight across the completed row.
4. **Inventory item pickup** — Fly a tiny icon toward the inventory anchor.
5. **Card deal** — Stagger cards from deck anchor into aligned slots.
6. **Progress fill catchup** — Animate the bar toward authoritative data without resetting it.
7. **Team swap transition** — Crossfade team branding while preserving text hierarchy.
8. **Shot meter reset** — Return meter to neutral after a short readable feedback interval.
9. **Pass target ping** — Brief pulse around a teammate marker without obscuring play.
10. **Countdown numbers** — Scale each number briefly; sync visuals to a single authoritative timer.
11. **Lobby ready check** — Change icon and color and announce the state in text.
12. **Reward carousel** — Slide reward cards with bounded inertia and focus retention.
13. **Popup stack** — Offset multiple popups and remove oldest first.
14. **Tab underline move** — Tween indicator position while content changes immediately.
15. **Toast slide** — Enter from an edge, linger, and depart after enough reading time.
16. **Quest arrow nudge** — Move arrow a few pixels then stop when the objective is visible.
17. **Pointer hold charge** — Fill a radial indicator while the button is held.
18. **Hover glow** — Tween stroke transparency, respecting reduced-motion preferences.
19. **Stat comparison** — Animate only changed comparison values.
20. **Map marker bounce** — One short bounce on newly discovered places.
21. **Emote preview loop** — Loop only in preview, stop on close.
22. **Character selection turn** — Rotate a preview model with a short eased motion.
23. **Page skeleton reveal** — Fade placeholders away when real contents load.
24. **Rank promotion card** — Build reveal in tiers, from title to details.
25. **Results timeline** — Sequence score, rewards and choices, with a skip affordance.
