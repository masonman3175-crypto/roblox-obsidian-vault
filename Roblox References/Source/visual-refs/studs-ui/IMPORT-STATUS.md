# Import status — actual stud UI screenshots

**No third-party screenshots or Roblox UI kit files have been imported in this update.** Their public preview pages are linked from [README.md](README.md). Preview visibility and free game-use licenses do not authorize bundling another creator's images or downloadable kits into this public repository.

## Rights check

- RBLX Essentials, [Studded UI Free](https://rblx-essentials.itch.io/studded-ui): creator explicitly permits personal/commercial **game use** but prohibits standalone redistribution. **Do not copy its ZIP, Studio model, or screenshots into this repository without explicit permission.**
- [Studded Settings GUI on BuiltByBit](https://builtbybit.com/resources/studded-settings-gui.88808/): explicitly says **do not redistribute**.
- The other [creator projects linked in README](README.md#creator-published-stud-ui-references-external-sources) have **no verified repository-redistribution permission** in this audit. Treat these as external references only.
- Seven pre-existing PNG screenshots remain in the parent folder. Their source/licence is **not verified**; they are not newly imported files.

## How to import a real reference

1. Get explicit permission from the author to **redistribute the screenshot in a public GitHub repo**, or locate an applicable licence allowing it.
2. Save an actual PNG image in `visual-refs/studs-ui/creator-references/`; no recreated SVGs or invented screenshots.
3. Add a manifest entry with `filename`, `title`, `creator`, `source_url`, `license_or_permission`, `permission_url_or_evidence`, and `import_date`.
4. Verify the screenshot is genuine and files display correctly. Do not label links as imported PNGs.

## Permission request template

“Hi! I maintain an open-source Roblox UI inspiration library. May I include a screenshot of your stud UI design in my public GitHub repository with clear credit and a link to your original listing? I would not redistribute your editable UI kit or model files. Please let me know whether this specific screenshot use is permitted and any conditions you want attached.”

**This repo needs authentic, usable visual references; accuracy and creator permissions matter more than inflating the file count.**
