# 37. Footsteps by Surface

Short steps with 4-6 variants per material, triggered by animation markers and Humanoid.FloorMaterial.

**Roblox recipe (general knowledge, see docs below):** map Enum.Material to a SoundGroup of variants; random pick avoiding repeat.
