# 1. Button Click

Short, dry, mid-high click (30-120 ms) that confirms a press. Keep it quiet and consistent: players hear it hundreds of times.

**Roblox recipe (general knowledge, see docs below):** Sound in a UI SoundGroup at Volume 0.3-0.5, play with SoundService:PlayLocalSound so it does not replicate; vary PlaybackSpeed 0.97-1.03 only.
