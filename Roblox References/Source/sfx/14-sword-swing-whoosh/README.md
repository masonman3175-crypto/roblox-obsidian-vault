# 14. Sword Swing Whoosh

Fast airy whoosh (150-300 ms), several variants rotated.

**Roblox recipe (general knowledge, see docs below):** start the sound on the animation marker, 3-5 variants, PlaybackSpeed jitter 0.92-1.08.
