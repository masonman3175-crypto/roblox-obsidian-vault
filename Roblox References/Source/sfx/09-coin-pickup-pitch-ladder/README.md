# 9. Coin Pickup Pitch Ladder

Coin tick whose pitch rises on consecutive pickups, resetting after a pause.

**Roblox recipe (general knowledge, see docs below):** PlaybackSpeed = 1 + 0.05*combo capped at 1.6.
