# 2026-10-21 - Claude (Cade) - Ultimate Frisbee UI and shop

Game: Ultimate Frisbee, Studio place "Untitled Experience" (`81684535279790`). Full details are in [[Ultimate Frisbee - Current Build]].

## Done
- **Vault:** pulled, set up the [[Ultimate Frisbee - Game Hub]] / Design / Current Build / Roadmap notes, and pointed CLAUDE.md at them.
- **Power shop:**
  - Sports-neon style from `visual-refs/sports`, with rarity VFX and a dramatic unlock reveal.
  - Coin and Robux prices sit side by side. Coin packs are coin, stack, bag, chest.
  - Glossy basket SHOP icon, uploaded from `visual-refs/icons`.
- **One style everywhere:** shared `ReplicatedStorage.UIStyle` (palette, fonts, glow, background pattern).

- **Lobby:**
  - The info panel is gone. READY UP and SOLO PRACTICE are side buttons.

  - Explanatory UI text was cut everywhere (Cade's rule).
- **Weather:** random every match; the vote and lobby weather pads were removed (pads backed up in ServerStorage).
- **Loadout and ability bar:**
  - Up to 3 powers on Q / F / C, plus Super Saiyan on X as the ultimate slot, with a stamina line.
  - The throw/catch card sits above the bar.
- **Audit and review fixes:**
  - Self-catch scoring is blocked, and R reset only works in practice.
  - Abilities only work in a match or practice.
  - Saving uses DataStore with a session lock, retries, a shutdown wait and autosave.
  - Match coin payouts, with only the first 10 catches per match paying.
  - Robux productId guard.
  - `ServerScriptService.SelfTests` (passes).
- **Ponytail** Claude Code plugin installed for Cade.
