# raw/

Sources for the wiki: reference images, screenshots, clips, clipped pages, plugin docs.

- **Immutable.** AI reads these, never edits, renames, or deletes them.
- Name files `YYYY-MM-DD-short-name.ext` (example: `2026-10-16-muzzle-flash-ref.png`).
- Obsidian saves pasted images here automatically.
- To add one to the wiki, drop it here and tell the AI: `ingest raw/<file>`.
