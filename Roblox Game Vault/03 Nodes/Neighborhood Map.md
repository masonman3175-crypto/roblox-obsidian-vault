# Neighborhood Map

## Roblox Studio object
`Workspace.OBlockNeighborhoodMap`

## Layout

- North/south and east/west asphalt roads
- Four side roads and two alleys
- Sidewalk grid around the main intersection
- Four houses
- Four apartment buildings
- Corner store
- Community center
- Neighborhood park with trees and a court
- Eight streetlights
- `NeighborhoodSpawn`

The map is intentionally modular: every major area is a Model or named Part so it can be moved, decorated, or replaced later.

## Design direction

This is a fictional dense urban neighborhood layout for the game, using a block grid rather than copying a real address or exact neighborhood. Add gameplay systems, signs, NPCs, interiors, and landmarks as the game direction becomes clearer.
