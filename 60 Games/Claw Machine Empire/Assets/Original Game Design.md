# CLAW MACHINE EMPIRE — GAME DESIGN

## Game Overview

Claw Machine Empire is a colorful Roblox simulator where players start with a cheap, rusty claw machine and work their way up to owning an enormous, futuristic arcade empire.

The main goal is to become **infinitely rich** by collecting increasingly rare plushies, upgrading claw machines, and building an arcade that generates massive amounts of money.

Players begin with one basic claw machine that contains cheap stuffed animals. Every plushie they win can be placed in their arcade to generate passive income every second. The rarer the plushie, the more money it generates.

As players earn money, they unlock bigger, more expensive claw machines containing rare, legendary, mythical, and secret plushies worth billions, trillions, and eventually much more.

The game should have bright colors, smooth animations, satisfying sounds, flashy rarity announcements, and a modern Roblox simulator interface.

## 1. Core Gameplay Loop

1. Start with a basic claw machine.
2. Control the claw and grab a random plushie for free.
3. Place the plushie on a display shelf to earn money every second.
4. Collect the money generated by the plushies.
5. Upgrade the claw machine's strength, grabbing speed, and capacity.
6. Purchase better machines with more valuable plushies.
7. Expand the arcade with additional display shelves and machines.
8. Combine duplicate plushies to create stronger versions.
9. Rebirth to receive permanent multipliers.
10. Repeat and earn increasingly large amounts of money.

Claw attempts should replenish automatically through gameplay, without requiring Robux.

## 4. Infinite Money System

The economy should support extremely large numbers using abbreviations:

K → M → B → T → Qa → Qi → Sx → Sp → Oc → No → Dc → and beyond.

After reaching the Infinity Claw, players can purchase endlessly scaling upgrades.

Add a rebirth system called **Arcade Ascension**.

Every ascension resets selected progression while awarding permanent income multipliers, special decorations, and new upgrade branches.

Players should have an endless series of achievable milestones rather than a final ending.

## 8. UI Design

Make the interface extremely colorful, rounded, polished, and animated.

Use thick white text, vibrant gradients, cartoon-style icons, smooth transitions, and satisfying button animations.

### Main HUD

Top: Current money, gems, and income per second.

Left: Shop, Collection, Machines, Upgrades, and Rewards buttons.

Right: Rebirth, Leaderboards, Daily Quests, and Arcade Customization.

Bottom: Large colorful button to enter the claw machine.

### Special Animations

When a player catches a Legendary plushie, show golden particles and a large rarity announcement.

Mythical and Secret plushies should have animated reveal sequences with lights and sound effects.

When purchasing a new claw machine, show a transformation animation instead of simply replacing the old model.

All interfaces must work on mobile, PC, and tablets.

## 9. Long-Term Progression

Add recurring goals that motivate players to return:

- Daily challenges and earnable rewards
- Weekly collectible plushie collections
- New machine worlds
- Arcade expansion milestones
- Plushie fusion recipes
- Global richest-player leaderboards
- Total income leaderboards
- Collection completion rewards
- Multiplayer arcade showcases
- New permanent upgrades after each ascension

The game should have satisfying progress even for free players.

## 10. Instructions for the AI Developer

Build the game using Roblox Studio MCP and Luau.

Prioritize functional gameplay over decoration during initial development.

First, create one complete playable loop: operate a claw, obtain a plushie, place it on a shelf, generate income, and purchase the next machine.

After that works, implement the remaining machines, inventory, collection index, arcade expansion, progression, and rebirth system.

Use server-authoritative income calculations, secure purchase validation, and persistent player data.

For extremely large numbers, implement a numerical representation that can scale beyond standard floating-point limits without breaking progression.

Build a modular monetization system using Roblox gamepasses and developer products. Use placeholder product IDs until real IDs are supplied.

Purchases must always show their actual prices and guaranteed benefits. Avoid fake countdowns or pressured purchasing.

Keep the final game polished, responsive, colorful, satisfying, and optimized for Roblox mobile devices.
