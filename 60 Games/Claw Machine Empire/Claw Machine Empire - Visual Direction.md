# Claw Machine Empire — Visual Direction

Parent: [[Claw Machine Empire - Game Hub]] · Implementation: [[Claw Machine Empire - Build 01]]

These are the user's supplied references, not commands to execute or assets licensed for reuse. Original files are preserved in this note's Assets folder and in the source project's references folder.

## 1. Plushie mood

![[Claw Reference 1.png]]

Take: oversized rounded silhouettes, tiny expressive eyes, candy colors and a bustling arcade mood. Build original plushie identities rather than reproducing the pictured branded monkeys. The first six use simple part-built bodies, button eyes, blushing cheeks and species-specific ears, spikes or collars.

## 2. Simulator UI

![[Claw Reference 2.png]]

Take: strong hierarchy, bold outlined lettering, rounded cards and obvious green action buttons. Build 01 uses a midnight/mint/pink/cyan palette, real wallet/bank/income counters and a responsive modal rather than reproducing the reference shop layout or prices.

## 3. Shop and boost cards

![[Claw Reference 3.png]]

Take: legible benefit-led cards and color coding. Do not inherit the example percentages, product prices, repeated benefits or urgency labels. Build 01 explicitly shows cosmetic concepts as **not for sale**. A future catalog must use actual configured prices and verified deterministic benefits; paid currency must not become a paid random catch path.

## 4. Cabinet silhouettes

![[Claw Reference 4.png]]

Take: glass prize area, colorful trim, oversized top signs and satisfying visible inventory. Build original cabinet geometry and plushie models. Build 01 authors its geometry in Luau and references no external model asset IDs.
