- `Roblox Game Vault/06 Tasks` — next steps

## Open it in Obsidian

Clone this repository, then open the repository folder as an Obsidian vault.

## Sync it

From the vault folder, run:

```powershell
.\sync-vault.ps1
```

That pulls remote changes, commits local changes, and pushes the result.
