# Roblox Obsidian Vault

Public documentation vault for the Roblox game **o blah warfare 1.1**.

## Contents

- `Roblox Game Vault/00 Dashboard` — starting point
- `Roblox Game Vault/01 Game Design` — game direction
- `Roblox Game Vault/02 Systems` — mechanics
- `Roblox Game Vault/03 Nodes` — Roblox Explorer tree
- `Roblox Game Vault/04 Scripts` — script documentation and source
- `Roblox Game Vault/05 Assets` — sounds and assets
- `Roblox Game Vault/06 Tasks` — next steps

## Open it in Obsidian

Clone this repository, then open the repository folder as an Obsidian vault.

## Sync it

From the vault folder, run:

```powershell
.\sync-vault.ps1
```

That pulls remote changes, commits local changes, and pushes the result.
